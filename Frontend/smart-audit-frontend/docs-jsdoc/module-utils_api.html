Module: utils/api

Utilidades para construir URLs de la API REST y del endpoint SSE. Lee la base de la URL desde la variable de entorno VITE_API_BASE_URL (definida en .env / .env.production). Si no está definida, usa http://localhost:8000.

(static, constant) buildApiSseUrl

Construye la URL para el endpoint SSE, añadiendo queryParams al query string. Se usa principalmente para el endpoint de progreso de escaneo, que recibe el token en la query porque EventSource no admite headers personalizados.
Source:
  • utils/api.js, line 41
Example
buildApiSseUrl('/cloud/scan_progress_sse/abc123', { token: 'eyJhbG...' })
// → 'http://localhost:8000/cloud/scan_progress_sse/abc123?token=eyJhbG...'

(static, constant) buildApiUrl

Construye la URL completa para una llamada REST al backend. Garantiza que haya exactamente una barra entre la base y el path, independientemente de cómo venga el path.
Source:
  • utils/api.js, line 22
Example
buildApiUrl('/cloud/my-audits/123')
// → 'http://localhost:8000/cloud/my-audits/123'
